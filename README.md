# 番茄工作法计时器

一个简洁优雅的番茄钟网页应用，帮助你实践番茄工作法，提升专注效率。

## 功能

- **番茄计时** — 默认 25 分钟专注 + 5 分钟休息，支持自定义时长
- **环形进度条** — 直观展示当前番茄钟的剩余时间
- **桌面悬浮窗** — 使用 Chrome Picture-in-Picture API，计时器始终悬浮在屏幕角落
- **完成提示音** — 工作/休息结束时播放不同音效
- **历史记录** — 自动保存每次完成记录，按日期分组展示
- **今日统计** — 显示当天已完成的工作番茄数
- **本地存储** — 设置和历史记录保存在浏览器 localStorage 中

## 使用方法

1. 直接用浏览器打开 `index.html`
2. 点击中间的播放按钮开始计时
3. 点击悬浮窗按钮将计时器弹出到桌面角落
4. 在偏好设置中调整工作和休息时长

## 技术栈

- HTML5
- CSS3
- 原生 JavaScript
- Document Picture-in-Picture API（需要 Chrome 116+）
